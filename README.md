Script,Purpose,Description
npm start,Development,Starts the local development server (usually on http://localhost:3000). It watches for file changes and reloads the application automatically. It is where you spend most of your development time.
npm test,Testing,"Launches the Jest test runner in an interactive ""watch mode,"" which automatically re-runs tests related to files you've changed. Essential for ensuring code quality and preventing regressions."
npm run build,Production,"Compiles, bundles, and optimizes your application for deployment. It creates static files (HTML, CSS, JavaScript) in a build folder that are ready to be served by any web server."
